Picxly – AI Photo Curation Platform
Overview
Picxly automatically curates the best images from large photo collections using computer vision. It scores images for emotion, sharpness, and composition, removing the need for manual selection.

Features
AI-based image selection

Emotion and sharpness scoring

Face recognition for key individuals

Batch processing for 1,000+ images

Ready-to-use curated output

Tech Stack
Python, YOLOv8, InsightFace, DeepFace, OpenCV, NumPy, Pandas

How It Works
Upload a folder of event images

Detect faces and score expressions

Evaluate image sharpness

Rank and export top images
